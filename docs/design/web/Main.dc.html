Darkroom, web UI for owner sign-off

Safelight, dark

One dark theme only: warm near-black ground, warm off-white ink, and one amber-red safelight accent for primary actions and alerts. Green, amber and red appear only as status, always with a text label and a distinct shape.

Seven screens, each at desktop (1280) and phone (390). The token set is on 00 Theme tokens. All people, accounts and devices are made up.
