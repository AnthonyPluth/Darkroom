Darkroom

Setup isn't open

Darkroom's first-run setup opens only when all of these hold:

  • DARKROOM_WIZARD=1 is set in the container's settings.
  • Setup hasn't been finished, and sign-in isn't set up in the environment.
  • This device is on your home network.
  • You opened http://<server's address>:8000/setup directly, not through Traefik or another proxy.
  • After the test sign-in: you're still signed in, on the browser that started setup.

If setup was closed before you finished, sign in and carry on from the People page. Settings are changed in Darkroom's environment.

Darkroom

Setup is open in another browser

Another browser started Darkroom's setup first, and only that browser can continue it. Finish it there.

If that browser is lost, run python run.py reopen-setup in the Darkroom container's console, then press Try again. After the test sign-in, that closes setup instead; sign in and carry on from the People page.
