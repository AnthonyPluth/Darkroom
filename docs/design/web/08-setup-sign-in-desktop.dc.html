Sign-in

1. Add Darkroom to Pocket ID

In Pocket ID, add an OIDC client for Darkroom with this callback URL:

http://192.168.1.20:8000/auth/callback

2. Enter the client's details

Pocket ID's address, such as https://id.example.com. Use https:// unless Pocket ID is on your home network.
People in any of these Pocket ID groups may sign in. Separate them with commas.
Or these people, by email. Separate them with commas. Set at least one group or address.

3. Test the sign-in

Sign in with your own account, one these details allow. If it works, Darkroom keeps these details, you stay signed in, and setup carries on with Immich. Only you, on this browser, can continue it from then on.
