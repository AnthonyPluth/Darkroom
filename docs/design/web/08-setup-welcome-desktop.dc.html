Set up Darkroom

This sets Darkroom up on this server, from this browser, from the first sign-in to the people, Google accounts and Pixels. You'll need:

  • The address you open Darkroom at (this one, most likely).
  • A client for Darkroom in Pocket ID: its issuer address, client ID and client secret.
  • Immich's address, and an Immich API key for each person.
  • Each person's Google account and its password, to sign in once in Darkroom's remote browser.
  • Each Pixel, with its Syncthing app's device ID.
  • Optionally, a Resend API key for alert emails.

You won't be asked to invent a password or a key: Darkroom makes and keeps its own.

Once you start, only this browser can continue. After the test sign-in, only you, signed in on this browser, can.
